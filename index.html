02 / Event-driven automation

projectX

Crypto-market monitoring & execution workflows

In development · Private source

TypeScriptNode.jsWebSocketsREST/RPC

A private crypto-market automation project for NFT monitoring and transaction workflows. It combines event-driven processing, configurable rules and guarded execution, with separate operational concerns for monitoring, decisions and notifications.

Engineering overview
System design
Event ingestion, normalization, cached metadata and rule evaluation are organized into a processing pipeline. Modules retain separate runtime, configuration and state boundaries.
Reliability and validation
TypeScript checks, automated tests, duplicate suppression and bounded notification queues support change validation and controlled operation.
Operational controls
Shadow and dry-run modes separate observation and validation from live execution. Telegram notifications provide an operator-facing view of system events.

Private source · Strategy parameters, wallet configuration and operational data are not published.
